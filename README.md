# Boardgame Tracker

Projekt zur Entwicklung einer mobilen App zur Erfassung und Auswertung von Brettspielpartien.

Aktuell:
- MVP fachlich definiert
- Datenmodell und EF-Core-Initialmigration vorhanden
- Architektur v0.3: pragmatische Vertical-Slice-/Feature-Organisation
- erster Persistenz-Slice implementiert: Personen + Gruppen anlegen und laden
- Mobile Wireframe v0.2 vorhanden
- erstes unterstütztes Spiel: Arche Nova
