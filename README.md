# Boardgame Tracker – Scaffold v0.7.3

Gezielte UI-Korrekturen an Gruppenübersicht und Partievorbereitung.

- Gruppenfilter stehen direkt unter der Überschrift.
- Abstand zur letzten Partie ist reduziert.
- Gruppenname steht deutlich näher an „Partie vorbereiten“.
- Würfel sitzt weiter rechts im Kopfbereich.
- „Zoopläne auslosen“ und „Reihenfolge durchrotieren“ stehen
  nebeneinander.
- Zoopläne sind nach dem Auslosen zunächst nicht ausgewählt. Nur eine
  echte Auswahl erhält einen grünen Rahmen.
- In der Farbauswahl wird die aktuell gesetzte Farbe nicht erneut
  angeboten.

Keine Datenbankschemaänderung. Keine Migration.
